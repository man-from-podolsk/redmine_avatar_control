# Плагин Avatar Control (`redmine_avatar_control`) — аватары в Redmine

Наш плагин для Redmine 6.1+ (писался по исходникам 7.0.2), версия 1.0.0 от 23.11.2026. Заменяет сторонний `redmine_avatars`.
Архив: `redmine_avatar_control-1.0.0.zip`. Контекст и миграция: `redmine_migration_brief-2026-10-18.md`, раздел 12.

## Что умеет

Пользователь (*Моя учётная запись → Аватар*):

- **Своя картинка**: PNG, JPG, WebP или GIF. Картинка обрезается до квадрата 256×256, метаданные (геолокация с телефона и т. п.) удаляются.
- **Готовый аватар**: Инициалы, Узор, Пиксели, Цвет, Силуэт рисуются прямо на сервере и никуда не уходят. Кнопка «Перемешать» перерисовывает их с другими цветами и узором. Если администратор разрешит, доступны ещё стили Gravatar: Монстрик, Wavatar, Робот, Ретро. Они грузятся с gravatar.com по случайному коду, адрес почты не передаётся.
- **Стандартный**: то, что показал бы сам Redmine (инициалы или Gravatar).
- **Без аватара**: у этого пользователя аватар не показывается нигде.
- **«Не показывать мне аватары»**: личная настройка просмотра, скрывает все аватары для этого пользователя.

Администратор:

- то же самое для любого пользователя: *Администрирование → Пользователи → (пользователь) → Аватар*;
- *Администрирование → Модули → Avatar Control → Настроить*:
  - **режим**: показывать всем / только выбранные (у кого «Стандартный», тому ничего) / не показывать нигде;
  - **проекты без аватаров** (и, по желанию, их подпроекты);
  - **что разрешено пользователям**: своя картинка, готовые, готовые Gravatar, «Без аватара», отключение для себя, предельный размер файла;
  - **CSS-селекторы**, которые скрываются вместе с аватарами. По умолчанию `.assignee-initials`: это инициалы исполнителя, которые темы Rubylode рисуют своим скриптом;
  - **проверка сервера**: можно ли писать в папку картинок и есть ли ImageMagick.

Аватары скрываются там, где Redmine их рисует: задачи и их история, наблюдатели, действия, новости, форум, верхнее меню, диаграмма Ганта, страницы пользователей.

## Где хранится

- Картинки лежат в `<attachments_storage_path>/avatar_control/` (по умолчанию `/opt/redmine/files/avatar_control/`). Они попадают в бэкап вместе с вложениями и удаляются вместе с пользователем.
- Выбор пользователя хранится в его настройках (`user_preferences.others`). Миграций БД нет.
- Картинки отдаются по адресу `/avatar_control/<id>`, только тем, кому виден пользователь. Настройка «Требуется аутентификация» тоже действует.

## Установка

```bash
which convert magick || apt install -y imagemagick
cd /opt/redmine/plugins
unzip /tmp/redmine_avatar_control-1.0.0.zip      # появится папка redmine_avatar_control
chown -R www-data:www-data redmine_avatar_control
mv redmine_avatars /root/redmine_avatars.disabled   # старый плагин, если стоит
systemctl restart redmine                            # юнит Puma
```

После перезапуска откройте настройки плагина и проверьте блок «Проверка сервера».

### Перенос картинок из redmine_avatars

Это нужно, только если через `redmine_avatars` успели загрузить картинки (они лежат в `files/redmine_avatars/`). Старые файлы при переносе не трогаются.

```bash
cd /opt/redmine
sudo -u www-data env PATH="<путь к ruby/bundle>:$PATH" RAILS_ENV=production \
  bundle exec rake redmine:avatar_control:import_redmine_avatars DRY_RUN=1   # сначала посмотреть
# без DRY_RUN=1 — перенести; FORCE=1 — перезаписать уже загруженные в Avatar Control
```

## Удаление

```bash
mv /opt/redmine/plugins/redmine_avatar_control /root/
systemctl restart redmine
```

В базе остаются только ключи в настройках пользователей, на работу Redmine они не влияют. Папку `files/avatar_control` можно удалить вручную.

## Проверка после установки

1. Пункт «Аватар» есть в «Моей учётной записи», страница открывается.
2. Загрузить JPG с телефона: картинка видна в задаче, в истории и в верхнем меню.
3. Выбрать каждый готовый аватар, нажать «Перемешать»: картинки меняются.
4. Выбрать «Без аватара»: в задачах у вас аватара нет, у остальных есть.
5. Включить «Не показывать мне аватары»: аватаров нет нигде, в темах Rubylode пропадают и инициалы исполнителей.
6. Режим «Только выбранные»: аватары видны только у тех, кто выбрал картинку или готовый.
7. Режим «Не показывать нигде»: аватаров нет совсем.
8. Скрыть в проекте (с подпроектами и без): в этих проектах аватаров нет, в остальных есть.
9. Администратор меняет аватар другому пользователю из *Администрирование → Пользователи*.
10. Обычный пользователь открывает `/users/<чужой id>/avatar_control` и получает 403.
11. Загрузить SVG или файл больше лимита: появляется понятная ошибка, а не Internal error.
12. Удалить тестового пользователя: его файл пропал из `files/avatar_control`.

## Устройство (для доработки)

| Файл | Что делает |
|---|---|
| `init.rb` | регистрация плагина, настройки по умолчанию, подключение патчей |
| `lib/redmine_avatar_control/avatars_helper_patch.rb` | заменяет `AvatarsHelper#avatar`: решает, что рисовать (своя / готовый / стандартный / ничего), учитывая режим, проект и настройку зрителя; `avatar_control_tag` рисует превью на странице выбора |
| `lib/redmine_avatar_control/settings.rb` | настройки администратора, `hidden_here?(project, viewer)` |
| `lib/redmine_avatar_control/choice.rb` | выбор пользователя в `pref[:avatar_control]` и `pref[:avatar_control_hide_all]` |
| `lib/redmine_avatar_control/presets.rb` | готовые аватары: SVG на сервере и адреса Gravatar со случайным хешем |
| `lib/redmine_avatar_control/storage.rb` | загрузка: проверка типа по содержимому, ImageMagick без shell с таймаутом и лимитами памяти, PNG 256×256 |
| `lib/redmine_avatar_control/hooks.rb` | ссылки в «Моей учётной записи» и в карточке пользователя, CSS для скрытия элементов тем |
| `lib/redmine_avatar_control/user_patch.rb` | удаляет картинку вместе с пользователем |
| `app/controllers/avatar_control_controller.rb` | выдача картинки, страница выбора и сохранение |
| `app/views/avatar_control/edit.html.erb` | страница выбора аватара |
| `app/views/settings/_avatar_control_settings.html.erb` | настройки плагина |
| `lib/tasks/avatar_control.rake` | перенос картинок из `redmine_avatars` |
| `config/locales/ru.yml`, `en.yml` | переводы |

## Ограничения

- «Стандартный» при включённом Gravatar считается невыбранным: в режиме «Только выбранные» он скрыт, даже если у
  человека есть картинка на gravatar.com (без запроса к Gravatar это не узнать).
- Скрытие по проектам работает на страницах проекта (задачи, вики, действия проекта). На общих страницах
  (общий список действий, «Моя страница») проекта нет, там действуют режим и личная настройка.
- Инициалы исполнителя в темах Rubylode рисует скрипт темы, их скрывает CSS из настроек (`.assignee-initials`);
  для других тем селекторы добавляются там же.
